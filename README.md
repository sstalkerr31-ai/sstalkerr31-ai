# 🌤️ Hi, I'm sstalkerr31-ai

> Tools for people who look at Sky and think: *"I wonder how that works."*

I build a small ecosystem of open-source utilities for **Sky: Children of the Light** modding and reverse engineering. Everything is lightweight, Python-based, and made with a dark theme and a soft spot for golden-hour skies. 🕯️

## 🧰 The Sky Modding Suite

| Tool | What it does |
|---|---|
| 🌤️ **[Sky Shader Studio](https://github.com/sstalkerr31-ai/sky-shader-studio)** | Edit SPIR-V shaders (`.spv` / `.ref`) with a Visual Studio–style editor. One-key recompile, mass decompile/compile. |
| 🧊 **[SkyMeshStudio](https://github.com/sstalkerr31-ai/SkyMeshStudio)** | Work with Sky's mesh assets. |
| 🖼️ **[sky-ktx-bc7-decoder](https://github.com/sstalkerr31-ai/sky-ktx-bc7-decoder)** | Decode KTX / BC7 textures into editable formats. |
| 🌍 **[sky-localization-tool](https://github.com/sstalkerr31-ai/sky-localization-tool)** | Edit and manage localization files. |
| 🛠️ **[Sky Toolkit](https://github.com/sstalkerr31-ai/Sky-Children-of-the-Light-Toolkit)** | Modular PyQt6 toolkit: textures, localization and more in one app. |

**Textures → meshes → shaders → text.** That's most of Sky's pipeline covered.

## ⚠️ Note
All projects are unofficial fan tools, not affiliated with thatgamecompany. Use at your own risk and keep backups.
